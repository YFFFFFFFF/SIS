# 用户系统测试指南

> 适用版本：2026-08-11 本地测试版。本文只描述当前已经实现的功能，不包含企业 SSO、分布式部署和生产运维能力。

## 1. 测试准备

先阅读并执行 [测试环境说明](test_environment.md)：

```powershell
cd E:\SIS
.\scripts\check_test_environment.ps1
```

启动后访问：

- 前端：`http://localhost:5173`
- Swagger：`http://localhost:8080/swagger-ui/index.html`

本地 `dev` profile 使用 H2 内存数据库。后端重启会清空业务数据并重新创建测试账号。

## 4. 推荐测试顺序

### 4.1 登录和项目

1. 使用投资分析师登录。
2. 创建 `UAT-DEMO-001`，刷新浏览器后重新查询。

预期：登录成功；项目保存后刷新仍存在；必填字段缺失时显示中文错误。

### 4.2 方案和输入

1. 创建基准、保守两个方案。
2. 分别录入参数、投资项和融资方案。
3. 对其中一个方案使用 Excel 导入两次。

预期：方案与项目关联正确；重复导入后投资项和融资项数量不翻倍；错误单元格显示工作表、行号、字段和原因。

### 4.3 财务测算

1. 发起完整测算。
2. 查看 NPV、IRR、回收期和现金流。
3. 与财务黄金案例进行独立复核。

预期：任务成功结束；指标和现金流均有结果；非法输入不产生非预期 500。

### 4.4 风险和比较

1. 执行敏感性、目标反算、蒙特卡洛和风险规则评估。
2. 固定蒙特卡洛随机种子并重复运行。
3. 比较基准、保守和未测算方案。
4. 执行组合优化，再尝试空候选池。

预期：相同种子结果可复现；未测算方案以缺失值展示且不进入排名；空候选池显示中文业务错误。

### 4.5 报告

1. 生成并下载 Excel 报告。
2. 生成并下载中文 PDF。

预期：文件可打开；Excel 数据与页面一致；PDF 中文标题、标签和元数据可正确显示。

### 4.6 协作

1. 两个账号打开同一方案。
2. 新增带 `@用户名` 的评论，并尝试删除本人和他人的评论。
3. 获取、续期和释放字段锁；模拟锁过期后由另一用户获取。
4. 关闭页面或切换方案，观察在线状态。

预期：只有作者或管理员可以删除评论；在线用户不会重复；离开页面后主动下线，异常断开超过两分钟后被清理；他人持有的有效锁不能被普通用户覆盖。

### 4.7 固定审批和审计

1. 投资分析师提交方案。
2. 财务专员复核。
3. 项目经理批准或驳回。
4. 查询方案审计记录和变更时间线。

预期：流程顺序固定且不可配置；状态、操作者、时间和动作准确；已提交或批准方案按规则只读。

## 5. 已知限制

- 仅验证单实例协作；跨实例 SSE 广播和共享会话尚未建设。
- 本地 H2 数据随后端重启清空；PostgreSQL 环境不可使用相同重置方式。
- Playwright 已覆盖登录、项目持久化、方案、输入、测算和 Excel 报告；风险分析及多角色审批仍以接口回归和人工测试为主。
- PDF 仍需使用固定样例进行人工版式验收。
- Excel 已自动覆盖 1000 行导入；接近 10MB 上传上限和第三方复杂模板仍需兼容性测试。
- 权限类业务错误当前可能返回 HTTP 400，但响应业务码为 `FORBIDDEN`；后续统一 HTTP 语义。

## 6. 缺陷提交

发现问题后复制 [缺陷记录模板](defect_template.md)，并登记到 [缺陷台账](defect_register.md)。至少提供：

- 环境、账号角色和前置数据；
- 可重复的操作步骤；
- 实际结果、预期结果和截图或日志；
- 严重程度及是否阻断后续测试。

修复完成后必须填写根因、修复方式、回归用例和验证结果，不能只把状态改为“已解决”。
