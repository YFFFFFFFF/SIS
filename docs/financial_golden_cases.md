# 财务计算黄金样例

> 版本：V1.0
> 建立日期：2026-08-11
> 精度：金额 4 位小数；NPV 容差 0.05；IRR 和回收期容差 0.0005。

## 独立核验口径

- NPV 使用 `Σ CF_t / (1+r)^t`，建设期从 `t=0` 开始。
- IRR 为使 NPV 等于 0 的折现率；现金流无符号变化时返回无解，不使用默认值。
- 静态和动态回收期均在累计现金流跨零点处线性插值。
- 建设期利息、折旧、所得税和偿债计划先逐年展开再汇总。
- 期望值由独立 Excel 工作簿按上述公式复核，禁止用程序输出自动更新。

## GOLD-01 标准全资本金项目

输入：建设期 1 年、运营期 5 年；建设投资 1000、流动资金 50；售价 140、年产量 10、单位变动成本 40、年固定成本 300；所得税 25%、WACC 10%；直线折旧 5 年、残值率 0；全资本金。

项目现金流：`[-1000, 525, 575, 575, 575, 625]`。

| 结果 | 期望值 |
|---|---:|
| 总投资 | 1050.0000 |
| NPV | 1165.2939 |
| IRR | 0.4816 |
| 静态回收期 | 1.8261 |
| 动态回收期 | 2.1100 |
| ROI | 0.4762 |
| 资本金净利润率 | 0.3571 |

| 总投资 | 2307.9040 |

| 第 1、2 年项目现金流 | -1200.0000 / -800.0000 |
| 首个运营年现金流 / 利息 | 937.5627 / 104.6323 |

## GOLD-03 税率梯度、投产负荷和加速折旧

输入：建设期 1 年、运营期 6 年；建设投资 1000；售价 500、年产量 5、单位变动成本 100、年固定成本 200；首年负荷 60%；1～3 年税率 0%、4～6 年 12.5%；双倍余额递减折旧 6 年、残值率 4%。

| 结果 | 期望值 |
|---|---:|
| 首个运营年净现金流 | 1000.0000 |
| 第二、三运营年净现金流 | 1800.0000 |
| 第一、二年折旧 | 333.3333 / 222.2222 |
| 第四运营年所得税 | 212.6543 |

## GOLD-04 无解与异常边界

- 所有现金流均为负数时，指标集合中不存在 IRR。
- 建设投资进度之和不等于 1、宽限期大于等于还款期、税率区间重叠时拒绝计算。
- 亏损年度所得税为 0，不产生负所得税收益。
