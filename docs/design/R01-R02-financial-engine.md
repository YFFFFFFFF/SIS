## 1. 设计目标与范围

### 1.1 目标

将 M1 简化财务引擎升级为符合《建设项目经济评价方法与参数》（第三版）口径的标准财务评价引擎，支撑 PRD FR-01-01~04 及下游的敏感性（R-04）、反算（R-09）、蒙特卡洛（R-11）、比选（R-05）。

### 1.2 本次必做（In Scope）

1. 投资估算三级结构（建设投资分项 / 建设期利息 / 流动资金）+ 合计强校验（FR-01-01）；
2. 建设投资**分年流出**（修复 M1 中 `constructionSchedule` 只校验不使用的问题）；
3. 成本费用分项模型（外购原材料及燃料动力 / 人工及制造费用 / 折旧 / 摊销 / 财务费用）（FR-01-02）；
4. 折旧政策可选：年限平均法 / 双倍余额递减法 / 年数总和法，政策选择留痕（FR-01-02 约束）；
5. 贷款还本付息计划：等额本金 / 等额本息 / 到期一次还本；建设期利息按"当年借款半额计息"惯例资本化（替换 M1 恒定利息）；
6. 税率梯度（税收优惠期，如"三免三减半"）；
7. 利润流向分解输出（供瀑布图/桑基图）；
8. 三类现金流量表：项目投资 / 项目资本金 / 财务计划（FR-01-04）；
9. 指标口径修正与扩充（见 §7.3，含 ROI 口径修正的**破坏性变更**说明）；
10. 标准算例集（§9），用于 1‰ 精度回归。

### 1.3 本次不做（Out of Scope）

- 敏感性/反算/蒙特卡洛/组合优化（后续改造项，但本设计的引擎必须**可被批量重算调用**，见 §8.5）；
- 报告内容结构化与 PDF 导出（R-06）；
- 成本分项与收入按年变化的复杂编辑界面（前端 R-03 后跟进；本次 API 先支持年度序列）；
- 多产品/多币种。

## 2. 现状关键事实（改写依据）

摘自 `docs/upgrade_plan.md` §2.3，此处仅列与本设计直接相关的：

1. `FinancialEngine.calculate()`：总投资第 0 期一次性流出；`constructionSchedule` 仅校验条数；利息 = 总投资×loanRatio×利率（恒定）；仅年限平均折旧；无摊销；无成本分项；只生成 `PROJECT_CASH_FLOW` 一类报表。
2. `CalculationService.buildInput()`：从 `investment_item`（category 三分支）和 `financing_plan`（EQUITY/LOAN）装配 `FinancialInput`；建设进度默认均分。
3. `cash_flow_row.statement_type` 字段已存在（V1），当前固定写 `PROJECT_CASH_FLOW`。
4. `calculation_result` 已有 `formula_version`/`engine_version`/`input_hash` 溯源三字段。
5. 现有 `FinancialEngineTest` 断言基于 M1 口径（`ROI=0.1875` 为"净利润/建设投资"口径），R-02 将**修正口径并改写该测试**（见 §7.3 破坏性变更清单）。
6. 任务执行链：`CalculationWorker` 轮询 → `CalculationService.executeTask()` → 引擎 → `persistRows/persistMetrics`。

| 6 | — | — | `calculation_result` 不变（溯源三字段沿用） |

### 3.2 枚举与编码约定

**投资类别 `investment_item.category`**（兼容 M1 三值）：

| 编码 | 含义 | 层级 |
| --- | --- | --- |
| `CONSTRUCTION` | 建设投资（一级，可为汇总行） | 1 |
| `CONSTRUCTION_BUILDING` | 建筑工程费 | 2 |
| `CONSTRUCTION_EQUIPMENT` | 设备购置及安装费 | 2 |
| `CONSTRUCTION_OTHER` | 其他费用（含预备费） | 2 |
| `INTEREST_DURING_CONSTRUCTION` | 建设期利息 | 1 |
| `WORKING_CAPITAL` | 流动资金 | 1 |

规则：若存在二级分项，则一级 `CONSTRUCTION` 行不直接录金额（金额 = 分项合计，由服务层汇总）；`item_code` 自由文本（如 `1.1`、`1.2.1`），`parent_id` 指向父行。

**成本类别 `cost_item.category`**：`RAW_MATERIAL`（外购原材料及燃料动力）、`LABOR_MANUFACTURING`（人工及制造费用）、`OTHER_OPERATING`（其他经营成本，预留）。

**折旧政策 `depreciation_policy`**：`STRAIGHT_LINE`（年限平均法）、`DOUBLE_DECLINING`（双倍余额递减法）、`SUM_OF_YEARS_DIGITS`（年数总和法）。

**还款方式 `repayment_method`**：`EQUAL_PRINCIPAL`（等额本金）、`EQUAL_PAYMENT`（等额本息）、`BULLET`（到期一次还本，运营期付息）。

**报表类型 `statement_type`**：`PROJECT_CASH_FLOW`（项目投资现金流量表，融资前）、`EQUITY_CASH_FLOW`（项目资本金现金流量表，融资后）、`FINANCIAL_PLAN`（财务计划现金流量表）。

- 存量 `investment_item` 行：`item_code`/`parent_id` 为 NULL，视为一级行，行为不变；

- 存量 `cash_flow_row` 历史行：新列默认 0，仅作历史展示，不重算。

## 5. 计算规则（算法契约）

> 符号约定：`t` 为日历年序号（建设期 0..cY-1，运营期 cY..cY+oY-1）；`k` 为运营年序号（k = t − cY + 1，1..oY）。金额单位与输入一致（建议万元），引擎不做单位换算。

### 5.1 总投资与建设期

```
建设投资 C = Σ constructionEntries.amount
第 t 年建设投资流出 C_t = C × constructionSchedule[t]          (t = 0..cY-1)
流动资金 WC：在第一个运营年（k=1）投入，最后一个运营年（k=oY）全额回收
```

### 5.2 贷款提款与建设期利息（资本化）

```
第 t 年提款 D_t = C_t × loan.principalRatioOfConstruction
建设期利息（当年借款半额计息惯例）：
  IDC_t = (期初累计本金余额 + 当年提款 × 0.5) × r
  期初累计本金余额 = Σ(D_i + IDC_i), i < t
运营期初贷款本金 P0 = Σ(D_t + IDC_t) = C×贷款比例 + ΣIDC_t
建设期利息合计 IDC = ΣIDC_t
总投资 TI = C + IDC + WC
```

### 5.3 折旧（基数 B = 建设投资 C + 建设期利息 IDC）

| 政策 | 第 k 年折旧 |
| --- | --- |
| STRAIGHT_LINE | `B × (1 − residualRate) / depreciationYears`（k ≤ depreciationYears，之后为 0） |
| DOUBLE_DECLINING | 直线率 ×2 的余额递减：`dep_k = 期初账面净值 × 2/depreciationYears`；**最后两年改直线**：`(剩余净值 − B×residualRate) / 2`；k > depreciationYears 后为 0 |
| SUM_OF_YEARS_DIGITS | `(B − B×residualRate) × (depreciationYears − k + 1) / (n(n+1)/2)`（k ≤ n） |

### 5.4 摊销

`amort_k = amortizableAmount / amortizationYears`（amortizationYears > 0 且 k ≤ amortizationYears，否则 0）。

### 5.5 运营期还本付息（P0 = 运营期初本金）

**等额本金 EQUAL_PRINCIPAL**：
```
还本期 n = repaymentYears − graceYears（repaymentYears 含宽限期，编码勘误：原稿误写为按 repaymentYears 全额摊还）
年还本 Pr_k = P0 / n                                 (k > graceYears)
利息 Int_k = 期初本金余额_k × r
宽限期（k ≤ graceYears）：Pr_k = 0，Int_k = 期初余额 × r（余额不变）
```

**等额本息 EQUAL_PAYMENT**：
```
年供 A = P0 × r(1+r)^n / ((1+r)^n − 1)，n = repaymentYears − graceYears
Int_k = 期初余额 × r；Pr_k = A − Int_k（宽限期 Pr_k = 0）
```

**到期一次还本 BULLET**：`Int_k = P0 × r`（k < repaymentYears）；末年 `Pr = P0`；超过 repaymentYears 后利息为 0。

### 5.6 收入、成本与利润（运营年 k）

```
负荷因子 f_k：rampUp 中 year=k 的 loadFactor，缺省 1.0
收入 Rev_k = pricePerUnit × annualOutput × f_k
可变成本 Var_k = unitVariableCost × annualOutput × f_k
固定经营成本 Fix_k：LABOR_MANUFACTURING + OTHER_OPERATING
   —— 取数规则：costEntries 中 yearNo=k 的覆盖值优先，否则 yearNo=0 的达产默认值
经营成本 OpC_k = Var_k + Fix_k
利息 Int_k：见 5.5（无贷款 = 0）
利润总额 PBT_k = Rev_k − OpC_k − dep_k − amort_k − Int_k
适用税率 rate_k：taxSchedule 命中区间则取区间 rate，否则 taxRate
所得税 Tax_k = max(PBT_k, 0) × rate_k        （亏损年税为 0；亏损结转本期不做，见 §10 风险 W2）
净利润 NP_k = PBT_k − Tax_k
息税前利润 EBIT_k = PBT_k + Int_k
```

### 5.7 三类现金流量表

**(a) 项目投资现金流量表 PROJECT_CASH_FLOW（融资前，所得税后）**

```
调整所得税 AdjTax_k = max(EBIT_k, 0) × rate_k
建设期 t：净现金流 = −C_t
运营年 k：净现金流 = Rev_k − OpC_k − AdjTax_k − [k=1 时 −WC] + [k=oY 时 +WC]
        （= EBIT_k + dep_k + amort_k − AdjTax_k，首年再减 WC、末年加回 WC）
```
用途指标：项目投资 NPV、项目投资 IRR、静态/动态回收期（全部基于此表）。

**(b) 项目资本金现金流量表 EQUITY_CASH_FLOW（融资后）**

```
建设期 t：净现金流 = −(C_t + IDC_t) × (1 − loan.principalRatioOfConstruction)
   （资本金按反比分摊建设投资与建设期利息；无贷款时 = −(C_t + IDC_t)）
运营年 k：净现金流 = NP_k + dep_k + amort_k − Pr_k − [k=1 时 −WC×(1−贷款比例)] + [k=oY 时 +WC×(1−贷款比例)]
```
用途指标：资本金 IRR（`EQUITY_IRR`）。资本金净利润率见 §7.2。

**(c) 财务计划现金流量表 FINANCIAL_PLAN（资金来源与运用）**

```
每年：经营活动净现金流（= NP + dep + amort）、投资活动（建设投资/流动资金流出与回收）、
      筹资活动（资本金注入 +、贷款提款 +、还本 −、付息 −）、净现金流量、累计盈余资金
```
行结构按"活动类型"细分存储：`statement_type='FINANCIAL_PLAN'` 的行内 inflow/outflow 汇总，分解列照常写入；活动明细通过同一 task 下多行（每期一行，含三类活动净额）呈现——具体列映射见 §6.3 注。

### 5.8 折现与指标

```
NPV = Σ 净现金流_t / (1 + wacc)^t            （t 为日历年序号，建设期第 1 年 t=0 不折现）
IRR：净现金流序列的二分求解（沿用 M1 算法框架，区间 [-0.9999, 10]，100 次迭代）；
   无解（全正/全负/无变号）返回 null 而非 0（**口径修正**，见 §7.3）
静态回收期：累计净现金流由负转非负的年份插值（含建设期）
动态回收期：折现后同上
```
