# 投资测算系统用户使用手册

> 文档版本：V2.1
>
> 适用版本：2026-08-12 用户测试版
>
> 适用对象：投资分析师、财务专员、技术工程师、项目经理、系统管理员和业务测试人员

## 1. 手册说明

本手册面向已经可以访问系统的业务用户，说明如何使用和测试以下功能：

- 项目建档和项目维护；
- 测算方案创建和选择；
- 测算参数、投资、成本和融资数据录入；
- 财务测算和结果查看；
- 风险分析、方案比选和组合优化；
- 协同评论、在线状态和编辑锁；
- Excel、PDF 报告生成和下载；
- 固定审批流程和审计查询；
- 项目检索、标签管理和项目复盘。

本手册不包含系统安装、部署、启动和技术配置说明。用户只需使用系统管理员提供的访问地址和账号登录。

## 2. 登录系统

### 2.1 登录步骤

1. 打开系统访问地址。
2. 输入管理员分配的用户名和密码。
3. 点击“登录”。
4. 登录成功后进入“工作台看板”。

### 2.2 登录测试要点

- 正确账号和密码可以进入系统；
- 错误密码会显示明确提示；
- 登录失效后，系统会要求重新登录；
- 点击页面右上角“退出登录”后，应返回登录页；
- 重新登录后，用户只能使用所属角色允许的功能。

## 3. 用户角色和职责

不同角色看到的菜单基本一致，但可执行的操作不同。

| 角色 | 主要职责 |
|---|---|
| 投资分析师 | 创建项目和方案、维护主要输入、执行测算、风险分析、方案比选、生成报告、提交审批 |
| 财务专员 | 维护财务参数、成本和融资方案、执行财务复核、确认风险预警 |
| 技术工程师 | 维护建设投资、设备投资等技术投资数据 |
| 项目经理 | 管理项目和方案、执行测算、最终审批、查询审计记录和查看项目复盘 |
| 系统管理员 | 使用全部测试功能，维护风险规则，处理协同锁冲突 |

## 5. 推荐业务操作顺序

首次测试建议按以下顺序完成一条完整业务链路：

1. 登录系统；
2. 创建并选择项目；
3. 创建并选择测算方案；
4. 录入测算参数；
5. 录入投资项、成本分项和融资方案；
6. 执行财务测算；
7. 查看指标、现金流和决策辅助结果；
8. 执行风险分析；
9. 创建第二个方案并进行方案比选；
10. 生成并下载报告；
11. 提交审批；
12. 使用财务专员完成财务复核；
13. 使用项目经理完成最终审批；
14. 查询流程时间线和审计记录；
15. 在项目库中录入项目复盘。

## 6. 工作台看板

工作台看板用于快速了解当前项目整体情况。

### 6.1 可查看内容

- 项目数量；
- 项目组合净现值；
- 加权内部收益率；
- 风险预警数量；
- NPV 与 IRR 分布；
- 项目阶段分布；
- 行业投资额分布；
- 风险信号灯；
- 在途审批和待办事项。

### 6.2 测试要点

- 新建项目后，项目数量应相应变化；
- 完成测算后，收益类指标和图表应出现数据；
- 产生风险预警后，预警数量和风险列表应更新；
- 提交审批后，应在待办区域看到相应事项；
- 点击待办区域的“全部”应进入流程治理页。

没有项目或测算结果时，部分图表为空属于正常情况。

## 7. 项目管理

### 7.1 创建项目

1. 进入“项目管理”。
2. 如果右侧正在编辑已有项目，点击“重置”。
3. 填写项目编码和项目名称。
4. 选择项目类型和状态。
5. 按需填写所属部门、标签和项目说明。
6. 点击“保存项目”。

### 7.2 字段说明

| 字段 | 说明 |
|---|---|
| 项目编码 | 项目的唯一编码，创建后不能在页面修改 |
| 项目名称 | 项目的正式名称 |
| 项目类型 | 产业项目、基础设施、科技项目或其他 |
| 状态 | 草稿、启用或已归档 |
| 所属部门 | 项目所属业务部门 |
| 标签 | 用于项目库分类和检索 |
| 项目说明 | 项目背景、范围和补充说明 |

### 7.3 编辑和选择项目

1. 点击项目列表中的一行。
2. 右侧表单切换为“编辑项目”。
3. 修改项目名称、类型、状态、部门、标签或说明。
4. 点击“保存项目”。

点击项目行也会把该项目设置为当前项目，后续方案管理和方案比选都会使用当前项目。

### 7.4 测试要点

- 项目编码重复时应提示不能保存；
- 项目名称和必填字段为空时应显示中文提示；
- 保存成功后，项目应出现在列表中；
- 刷新页面后，项目仍应存在；
- 编辑项目后，列表应显示最新内容；
- 没有权限的角色不应能够创建或修改项目。

当前页面不提供项目删除功能。

## 8. 测算方案管理

### 8.1 创建方案

1. 先在“项目管理”页选择项目。
2. 进入“测算方案”。
3. 点击“重置”，确保右侧显示“创建测算方案”。
4. 填写方案名称。
5. 填写测算期和建设期。
6. 按需填写备注。
7. 保持状态为“草稿”。
8. 点击“保存方案”。

### 8.2 编辑和选择方案

1. 点击方案列表中的一行。
2. 修改方案名称、测算期、建设期或备注。
3. 点击“保存方案”。

选中方案后，测算输入、测算执行、风险分析、报告、审批和协同编辑等页面会使用该方案。

不建议直接手工把方案状态改为“已提交”或“已通过”，应通过流程治理页推进审批状态。

### 8.3 测试要点

- 未选择项目时，不能创建方案；
- 方案名称为空时应提示错误；
- 测算期和建设期超出允许范围时应提示错误；
- 保存后，新方案应出现在当前项目的方案列表中；
- 切换项目后，只应显示所选项目的方案；
- 没有权限的角色不能修改方案；
- 已进入受控审批状态的方案应按规则限制编辑。

当前页面不提供方案删除功能。

## 9. 测算输入

进入“测算输入”前，必须先选择测算方案。

### 9.1 测算参数

常用字段如下：

| 字段 | 填写说明 |
|---|---|
| WACC | 使用小数填写，例如 `0.10` 表示 10% |
| WACC 来源 | 填写参数来源或确定依据 |
| 所得税率 | 使用小数填写，例如 `0.25` 表示 25% |
| 折旧年限 | 填写正整数，单位为年 |
| 残值率 | 使用小数填写 |
| 贷款比例上限 | 使用小数填写，例如 `0.70` |
| 单位售价 | 单位产品销售价格 |
| 单位成本 | 单位产品变动成本 |
| 年产量 | 达产年份的预计产量 |
| 固定运营成本 | 每年的固定运营支出 |
| 折旧政策 | 年限平均法、双倍余额递减法或年数总和法 |
| 摊销年限 | 填写 `0` 表示不摊销 |
| 摊销基数 | 需要进行摊销的金额 |
| 还款方式 | 等额本金、等额本息或到期一次还本 |

填写完成后点击“保存参数”。

### 9.2 税率梯度和投产负荷

这两个字段用于复杂场景，普通测试可以留空。

税率梯度示例：

```json
[{"fromYear":1,"toYear":3,"rate":0}]
```

表示运营第 1 至第 3 年税率为 0。

投产负荷示例：

```json
[{"year":1,"loadFactor":0.6},{"year":2,"loadFactor":0.8}]
```

表示投产第 1 年负荷为 60%，第 2 年为 80%。

填写时必须保持示例中的格式。格式错误时，系统应阻止保存或测算，并显示错误提示。

### 9.3 投资项目

1. 选择投资类别。
2. 填写项目名称和金额。
3. 填写发生年份。
4. 可填写分项编码。
5. 点击“新增投资项目”。

可选类别包括建设投资、建筑工程费、设备购置及安装费、工程建设其他费用、流动资金和建设期利息。

### 9.4 成本分项

1. 选择成本类别。
2. 填写分项名称和金额。
3. 填写运营年。
4. 点击“新增成本分项”。

运营年填写 `0` 表示达产年通用成本。

### 9.5 融资方案

1. 选择资本金或银行贷款。
2. 填写融资比例和金额。
3. 填写利率和期限。
4. 选择还款方式。
5. 填写宽限期。
6. 点击“新增融资方案”。

融资比例使用小数填写，例如 `0.30` 表示 30%。

### 9.6 测试要点

- 未选择方案时，保存和新增按钮应不可用；
- 不同角色只能维护其权限范围内的数据；
- 金额、比例、税率和期限不符合要求时应提示错误；
- 保存参数后，再次进入页面应显示已保存值；
- 新增投资、成本和融资数据后，应在对应列表中出现；
- 他人锁定的字段应显示锁定状态并禁止编辑；
- 方案进入只读状态后，不应继续修改受控输入。

## 10. 执行财务测算

### 10.1 发起测算

1. 确认当前方案已经保存参数。
2. 确认已经录入投资项和融资方案。
3. 进入“测算执行”。
4. 保留或修改请求标识。
5. 点击“开始测算”。
6. 等待测算完成。
7. 如结果未自动更新，点击“刷新结果”。

### 10.2 测算状态

测算任务可能处于以下状态：

- 待处理；
- 运行中；
- 成功；
- 失败。

测算失败时，应根据页面提示检查参数、投资、融资和高级输入，再重新测算。

### 10.3 核心指标

测算成功后，可以查看指标表格和图表，主要包括：

- 净现值 NPV；
- 内部收益率 IRR；
- 静态回收期；
- 动态回收期；
- 总投资；
- 其他财务评价指标。

### 10.4 现金流和附表

系统提供：

- 项目投资现金流；
- 项目资本金现金流；
- 财务计划现金流；
- 达产年利润流向分解；
- 银行贷款还本付息计划。

### 10.5 测试要点

- 输入完整时，测算应成功完成；
- 测算成功后应显示 NPV、IRR 和现金流；
- 输入缺失或不合理时，应显示可理解的中文错误；
- 常规用户操作不应出现系统异常或空白页面；
- 修改售价、成本或投资额后重新测算，结果应发生合理变化；
- 售价上升通常应改善收益；
- 投资额或单位成本上升通常应降低收益；
- 重复测算不应混用其他方案的数据；
- 财务人员应使用约定的标准案例独立复核核心指标。

## 11. 决策辅助

完成测算后，可以在“测算执行”页查看决策辅助功能。

### 11.1 智能打分

点击“智能打分”后，系统显示：

- 综合得分；
- 建议立项、谨慎推进或建议暂缓；
- 各评价因素得分；
- 权重和加权结果；
- 打分依据。

### 11.2 参数推荐

点击“参数推荐”后，系统显示：

- 当前参数值；
- 建议区间；
- 推荐依据。

### 11.3 使用说明

当前决策辅助依据规则、财务指标和系统内数据生成建议，只作为业务参考，不能代替专业复核和正式审批。

### 11.4 测试要点

- 未完成测算时，不应返回无依据的评分；
- 评分应显示具体因素和依据；
- 参数推荐应显示当前值和建议区间；
- 相同输入下结果应保持稳定；
- 页面应明确提示结果仅供辅助决策。

## 12. 风险分析

进入“风险分析”前，应先选择方案并完成测算。

### 12.1 敏感性分析

1. 选择目标指标 NPV 或 IRR。
2. 选择第一个影响因素。
3. 设置波动区间和步数。
4. 可选择第二个因素；不选择时执行单因素分析。
5. 点击“运行敏感性分析”。

测试时检查结果表格、热力图和龙卷风图是否一致。

### 12.2 目标反算

1. 选择目标指标：NPV、IRR 或静态回收期。
2. 填写目标值。
3. 选择需要反算的变量：售价、投资额、年产量或单位成本。
4. 点击“目标反算”。

结果应显示临界值、基准值、变动幅度、达成值和适用边界。目标无法达到时，应显示明确的不可达提示。

### 12.3 盈亏平衡分析

点击“运行盈亏平衡分析”，查看：

- 盈亏平衡产量；
- 盈亏平衡利用率；
- 收入与成本曲线；
- 盈亏平衡点。

### 12.4 蒙特卡洛分析

1. 选择目标指标。
2. 设置抽样次数。
3. 可填写随机种子。
4. 添加分析变量并设置分布参数。
5. 点击“运行蒙特卡洛”。

系统显示均值、正值概率、风险价值、分布直方图和累计分布。

比较不同方案时，应使用相同的抽样次数、变量和随机种子。相同输入和随机种子的结果应可重复。

### 12.5 风险预警

- 点击“按最新测算评估风险”生成或更新预警；
- 点击“刷新”重新加载规则和预警；
- 对开放状态的预警点击“确认”；
- 管理员可以新增、编辑、删除和启停风险规则。

### 12.6 测试要点

- 未选择方案时，分析按钮应不可用；
- 未完成测算时，应提示先执行测算；
- 非法波动区间、变量或分布参数应被拒绝；
- 相同随机种子的蒙特卡洛结果应一致；
- 敏感性表格与图形应使用相同数据；
- 风险恢复正常后，预警状态应相应更新；
- 普通用户不能维护管理员风险规则。

## 13. 方案比选

### 13.1 准备比选方案

1. 在同一项目下创建至少两个测算方案。
2. 为每个方案录入不同的售价、成本、投资或融资假设。
3. 分别完成测算。
4. 在“项目管理”页选择对应项目。
5. 进入“方案比选”。

### 13.2 查看比选结果

系统会显示：

- 多方案指标矩阵；
- 各指标最优方案标记；
- 方案排名建议；
- 未测算方案的缺失状态。

指标方向规则：

- NPV、IRR 等收益指标越高越优；
- 回收期越低越优；
- 总投资等中性指标用于展示，不一定标记最优；
- 未测算方案不进入有效排名。

### 13.3 测试要点

- 页面只比较当前项目下的方案；
- 未测算方案应显示为空值；
- 未测算方案不应进入排名；
- 排名顺序应与指标值一致；
- 最优标记应符合指标方向；
- 不存在的项目应显示明确错误，而不是空白页面。

## 14. 组合优化

组合优化使用系统内所有已经测算成功的方案作为候选。

### 14.1 操作步骤

1. 进入“方案比选”。
2. 切换到“组合优化”页签。
3. 填写资金池预算。
4. 可填写方案数量上限；留空表示不限制数量。
5. 点击“运行组合优化”。

### 14.2 查看结果

页面显示：

- 组合 NPV；
- 组合总投资；
- 预算利用率；
- 入选方案数量；
- 候选方案列表；
- 入选与未入选状态；
- 组合求解说明；
- 帕累托前沿。

### 14.3 测试要点

- 预算必须大于 0；
- 数量上限应限制最终入选数量；
- 组合总投资不应超过预算；
- 组合汇总指标应等于入选方案汇总值；
- 没有成功测算方案时，应提示没有可用候选方案；
- 图表、表格和汇总指标应保持一致。

## 15. 协同编辑

### 15.1 选择协同对象

1. 进入“协同编辑”。
2. 选择项目。
3. 选择测算方案。

页面显示在线用户、数据字段、锁定状态、变更记录和评论。

### 15.2 在线状态

- 用户进入方案后应显示为在线；
- 同一用户不应重复显示；
- 用户切换方案或离开页面后，应从原方案在线列表移除；
- 用户异常离开时，在线状态会在短时间后自动清理。

### 15.3 评论和提及

1. 在评论框输入内容。
2. 使用 `@用户名` 提及同事。
3. 点击“发送”。

示例：

```text
请 @finance_specialist 复核融资利率和所得税率。
```

评论作者可以删除本人评论；管理员可以删除任意评论；普通用户不能删除他人评论。

### 15.4 字段锁

| 状态 | 可执行操作 |
|---|---|
| 字段未锁定 | 点击“锁定编辑” |
| 本人持有 | 编辑完成后点击“完成并释放” |
| 他人持有 | 等待对方释放或锁过期 |
| 管理员处理冲突 | 点击“强释” |

字段锁用于避免多人同时修改相同数据。锁定字段后，可以前往“测算输入”页完成修改。

### 15.5 变更记录

变更时间线应记录：

- 变更类型；
- 变更字段；
- 操作人；
- 操作时间；
- 变更内容；
- 递增版本号。

### 15.6 测试要点

- 两个用户进入同一方案时，应互相看到在线状态；
- 评论应实时出现在双方页面；
- 评论中的提及用户应被正确识别；
- 非作者删除他人评论时应被拒绝；
- 他人持有的有效字段锁不能被普通用户覆盖；
- 本人可以续期和释放锁；
- 锁过期后，其他用户可以重新获取；
- 管理员可以强制释放锁；
- 评论和锁操作应进入变更时间线。

如果报告按钮不可点击，请先返回“测算执行”页确认当前方案已经成功测算。

## 17. 审批流程

当前系统使用固定审批流程：

```text
提交方案 → 财务复核 → 项目经理审批 → 审批通过
                         └→ 驳回
```

### 17.1 提交方案

1. 使用投资分析师、项目经理或管理员账号。
2. 选择需要提交的方案。
3. 进入“流程治理”。
4. 点击“提交方案”。
5. 记录页面返回的审批流程 ID。

提交后，流程进入“财务复核”节点。

### 17.2 财务复核

1. 使用财务专员账号登录。
2. 进入“流程治理”。
3. 输入审批流程 ID。
4. 点击“财务复核通过”，或点击“驳回”。

复核通过后，流程进入项目经理审批节点。

### 17.3 最终审批

1. 使用项目经理账号登录。
2. 进入“流程治理”。
3. 输入审批流程 ID。
4. 点击“最终审批通过”，或点击“驳回”。

### 17.4 流程时间线

流程时间线应显示：

- 流程节点；
- 审批决定；
- 操作人；
- 操作时间；
- 审批意见；
- 当前状态。

### 17.5 测试要点

- 投资分析师可以提交方案；
- 财务专员可以复核，但不能最终审批；
- 项目经理可以最终审批；
- 不符合当前节点的操作应被拒绝；
- 流程完成或驳回后，不能重复执行节点操作；
- 提交、复核、审批和驳回后，方案状态应同步变化；
- 流程顺序固定，页面不应提供流程定义修改入口；
- 每次操作都应进入时间线和审计日志。

## 18. 方案编辑锁

流程治理页提供方案级编辑锁，用于防止多人同时编辑整个方案。

### 18.1 获取锁

1. 选择方案。
2. 填写锁持有人 ID、持有人名称和有效时间。
3. 点击获取锁。

### 18.2 释放锁

锁持有人编辑完成后点击释放。其他用户持有有效锁时，系统应显示冲突提示；锁过期后，其他用户可以接管。

### 18.3 测试要点

- 首个用户可以正常获取锁；
- 第二个用户不能覆盖有效锁；
- 锁持有人可以释放锁；
- 非持有人不能释放他人的锁；
- 过期锁可以被新用户替换。

方案级编辑锁和协同编辑页的字段锁属于不同粒度的锁定机制。

## 19. 项目库

### 19.1 项目检索

项目库支持按以下条件检索：

- 关键字；
- 项目状态；
- 项目类型；
- 标签。

列表显示项目编码、名称、类型、状态、标签、最新 NPV、最新 IRR 和复盘状态。

### 19.2 标签管理

1. 点击项目行的“标签”。
2. 选择已有标签或输入新标签。
3. 点击“保存”。

保存后，应可以使用该标签检索到项目。

### 19.3 项目复盘

1. 点击项目行的“复盘”。
2. 选择一个对照测算方案。
3. 查看计划 NPV、IRR、总投资和回收期。
4. 填写实际 NPV、IRR、总投资和回收期。
5. 填写投产日期和经验教训。
6. 点击“保存复盘”。

保存后，页面应显示计划值、实际值和偏差。

### 19.4 测试要点

- 多个筛选条件可以组合使用；
- 清空条件后应恢复完整列表；
- 标签保存后应正确显示和检索；
- 复盘保存后，列表应显示“已复盘”；
- 再次进入复盘时，应显示上次保存的数据；
- 计划指标应来自所选测算方案。

## 20. 审计日志

审计查询通常由项目经理或管理员使用。

### 20.1 查询操作记录

1. 进入“审计日志”。
2. 填写对象类型。
3. 填写对象 ID。
4. 点击“查询”。

常用对象类型：

- `SCENARIO`：测算方案；
- `CALCULATION_TASK`：测算任务；
- `APPROVAL_INSTANCE`：审批流程；

### 20.2 校验日志链

点击“校验日志链”。如果日志完整，页面显示校验通过；如果发现异常，页面会显示异常事件数量和事件 ID。

### 20.3 测试要点

- 创建项目后应存在项目创建记录；
- 修改方案后应存在方案更新记录；
- 执行测算后应存在测算任务记录；

## 22. 常见问题

### 22.1 登录后没有可操作数据

请确认测试管理员是否已经准备演示项目，或使用有项目创建权限的账号先创建项目和方案。

### 22.2 页面提示先选择项目或方案

先进入“项目管理”点击项目，再进入“测算方案”点击方案，然后返回目标页面操作。

### 22.3 按钮是灰色的

可能原因：

- 没有选择项目或方案；
- 当前账号没有权限；
- 方案已提交或审批完成；
- 当前字段或方案被其他用户锁定；
- 当前方案尚未完成测算。

### 22.4 测算没有结果

检查是否已经保存参数、投资项和融资方案。修正输入后重新测算，并点击“刷新结果”。

### 22.5 风险分析无法运行

先确认当前方案已经成功测算。部分风险分析还要求选择变量或填写合理的分析范围。

### 22.6 报告按钮不可点击

先在“测算执行”页完成一次成功测算，再进入“报告中心”。如果中途重新登录或刷新页面，请重新选择项目和方案并加载测算结果。

### 22.7 不能编辑某个字段

检查字段旁的锁状态。其他用户持有锁时，需要等待其释放；管理员可以在“协同编辑”页处理异常锁。

### 22.8 审批按钮不可点击

检查当前账号角色、审批流程 ID 和当前流程节点。财务复核和最终审批必须由不同职责角色按顺序执行。

### 22.9 页面数据与预期不一致

确认当前选择的是正确项目、方案和最新测算任务。如果仍有问题，请记录操作步骤、实际结果和预期结果并提交缺陷。

## 23. 当前使用限制

- 当前页面不提供项目和方案删除功能；
- 当前页面不提供 Excel 文件导入入口，不作为普通用户页面测试项；
- 审批流程为固定流程，不提供流程自定义功能；
- 协同功能按单套已部署系统进行验证；
- 决策辅助结果仅供参考，不代替正式业务判断；
- PDF 报告需要重点进行中文显示和版式人工检查；
- 风险分析和多角色审批建议由不同测试账号配合完成。

## 24. 缺陷反馈要求

发现问题时，请至少提供：

- 测试账号和角色；
- 所属功能模块；
- 使用的项目和方案；
- 操作前的数据状态；
- 可重复的操作步骤；
- 实际结果；
- 预期结果；
- 截图或录屏；
- 问题是否阻断后续测试。

缺陷严重程度：

- 阻断：无法登录、核心流程中断、数据损坏或核心计算错误；
- 严重：主要功能不可用、权限绕过或报告无法使用；
- 一般：存在替代操作，但明显影响使用；
- 轻微：文案、样式或非关键体验问题。
