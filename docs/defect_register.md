# 缺陷台账

严重程度定义：

- 阻断：无法登录、主流程中断、数据损坏或核心结果错误。
- 严重：主要功能不可用、权限绕过、报告无法生成。
- 一般：存在替代路径，但影响操作或理解。
- 轻微：文案、样式和非关键体验问题。

新增缺陷时：

1. 从 [缺陷记录模板](defect_template.md) 创建详细记录。
2. 在本表登记编号、严重程度和当前状态。
3. 修复时增加可复现原问题的自动化回归用例。
4. 验证通过后填写验证日期和结果，再关闭缺陷。
